# AI Agent 主提示詞

複製下方內容，替換角括號中的資料後，完整交給程式型 AI Agent。

```text
你要替我製作一個 Windows 桌面小精靈。

基本資料：
- 寵物名稱：<名稱>
- 照片資料夾：<絕對路徑>
- 希望風格：<例如半寫實 2.5D>
- 專案輸出路徑：<絕對路徑>
- 自主活動間隔：50～300 秒

先聲明任務分級，再依序完成，不要只提供範例碼或建議。

第一階段：來源與隱私
1. 唯讀盤點照片資料夾，不修改來源照片。
2. 列出照片數量、角度與缺少的關鍵視角。
3. 不把來源照片、個資、絕對路徑或密鑰提交到 Git。
4. 只使用我擁有權利的照片；不要自行下載外觀相似但未授權的角色素材。

第二階段：角色身份
1. 從照片整理不可變特徵：臉型、眼距、鼻型、耳朵、毛色、身形、尾巴與腳掌。
2. 先產出正面與側面身份確認圖，不要一次生成全部動作。
3. 等我確認角色身份後，再建立透明 PNG 動作素材。
4. 所有動作維持相同角色、光源、相機高度、比例與半寫實 2.5D 風格。

第三階段：動作素材
至少建立：
- 正面待機，以及可分離的頭部與身體。
- 側面站立。
- 走路至少 4 幀。
- 跑步至少 6 幀。
- 坐下、跳躍、睡覺、撒嬌。
- 低頭撿球、含球回程與放球。

所有 PNG 必須透明背景、固定畫布、固定腳底錨點、無白邊、無文字。

注意這是**最終交付**的規格，不是生圖時的規格。生圖階段要向模型要求
「純白背景」（生圖工具做不出可靠的透明背景，硬要會得到髒邊），
切圖後再去背成透明。去背要切到真的透明，留下近白像素在深色桌布上會有光暈。
生圖的完整作法與 prompt 範本見 `skill/windows-desktop-pet-builder/references/asset-spec.md`。

第四階段：Windows 功能
使用 C# 與 WPF 製作：
- 透明無邊框、可置頂、不顯示在工作列。
- 可拖曳。
- 頭部與眼神平滑追蹤滑鼠。
- 單擊隨機反應、雙擊跳高、右鍵功能選單。
- 可調整大小並保存。
- 50～300 秒隨機走路、跑步、睡覺或撒嬌。
- 系統匣、單一執行個體、設定保存與錯誤日誌。

第五階段：動畫與物理
1. 使用高解析度計時器與 deltaTime，不可用每幀固定像素。
2. 移動加入加速度、慣性、接近目標減速與螢幕邊界。
3. 步態換幀速度必須跟實際速度連動。
4. 先直接查看側身素材真正面向的方向，再決定鏡像。
5. 眼睛圖層必須和頭部共用旋轉與平移；不要用純白橢圓眨眼遮罩。
6. 撿球拆成蓄力、重力飛行、落地衰減彈跳、追逐、低頭撿取、含球回程與放球。
7. 球的飛行使用重力公式，落地加入反彈、摩擦與旋轉。

第六階段：Windows 安全
1. 不停用 Smart App Control、防毒或其他 Windows 安全功能。
2. 未簽章 EXE 被阻擋時，提供 PowerShell Add-Type 原始碼啟動器，或說明正式簽章方案。
3. 所有 .ps1 使用 UTF-8 with BOM。
4. 不硬編碼任何密鑰。

第七階段：驗收
至少建立並實跑：
- --self-test：必要素材與設定檢查。
- --render-test：透明視窗渲染。
- --fetch-test：完整撿球流程。

另外人工或自動確認：
- 左右極端視線沒有白色殘影。
- 角色行進方向正確。
- 動畫速度不依賴幀率。
- 程式啟動後視窗可回應。
- 關閉後沒有殘留球視窗或系統匣圖示。

完成時回報：
- 已完成的功能。
- 實際執行的測試與結果。
- 所有新檔案與專案資料夾的絕對路徑。
- 啟動方式。
- 尚未驗證或需要我視覺確認的部分。
```
