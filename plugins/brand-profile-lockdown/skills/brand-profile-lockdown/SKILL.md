# Brand profile 鎖定

把 AI 當顧問與整理者，不當替使用者發明定位的寫手。從事實出發，經由「個性 pattern → 品牌資產 → 長期方向」收斂成可持續使用的 `brand-profile.md`。

## 引導邊界

訪談 phase 與模板是證據框架，不是要列完所有品牌原型。執行 Agent 應依使用者
材料調整問題與段落；沒證據的欄位可留白或標假設，不為了模板完整而發明定位。

## 執行契約

1. 先讀完使用者提供的背景、作品、筆記與既有 profile，再決定缺什麼。
2. 只問答案會改變定位的缺失問題；一輪問 3–5 題，一次完成一個 phase。
3. 每個 phase 都要依通過判準驗收；未通過就補證據、降級為假設或保留歧義，不替使用者補故事。
4. 可逆、低風險的新檔案可直接建立。若要覆寫既有 `brand-profile.md`、刪除私人材料或改寫使用者的事實，先說明差異並取得確認。
5. 個人經歷、數字、成就與原句只以使用者材料為準。推論必須標成「假設」並附證據，不得美化成更好看的版本。
6. 每完成一個 phase，先回報產物、證據缺口與是否通過，再進下一 phase。

## 適用與不適用

適用：個人品牌定位、創作者內容主軸、創辦人品牌、專業者的公開立場與長期內容邊界。

不適用：

- 只想改文風、口頭禪或標點習慣：改用 voice profile；brand profile 管「寫什麼、為什麼寫、站在哪裡」，voice profile 管「怎麼寫」。
- 公司品牌識別系統、Logo 或完整視覺規範：需要品牌策略與視覺設計流程。
- 沒有任何本人材料、又不願受訪：只能建立待驗證假設，不能宣稱已鎖定。
- 要替別人捏造經歷、成績或專家身分：拒絕。

## 開始前素材與輸入

先盤點現有材料，不要求使用者重貼已可讀取的檔案：

- 成長與轉折：環境、選擇、改變方向的事件。
- 做過的事：專案、作品、工作、實驗、公開紀錄。
- 失敗與代價：錯誤判斷、放棄、限制、反覆卡住的地方。
- 在意與反感：願意長期捍衛或拒絕的原則。
- 外部證據：公開連結、可展示成果、第三方回饋、具日期的紀錄。
- 原句：能代表本人思考方式的短句。只保留必要片段與來源位置。
- 既有定位或內容：用來找矛盾，不把舊版本當真理。

為每份材料編 `S01`、`S02`……來源 ID，記下類型、日期、擁有者、是否可公開。若材料含第三人隱私、客戶機密、醫療或財務資料，先去識別化；不需要的敏感細節不要複製進 profile。

## 產出檔與模板

主要產出是 `brand-profile.md`。先建立新檔；若檔案已存在，建立候選新版或 diff，確認後才替換。

```markdown
---
profile_type: brand
version: 1.0.0
updated_at: YYYY-MM-DD
status: draft | validated
owner: <name>
```

Evidence table 是防止 AI 美化的核心：每個 pattern 必須回指使用者事實或最短必要原句。沒有來源的漂亮句子刪除或標為低信心假設。

## 分 phase 執行

### Phase 0：盤點、邊界與檔案策略

**動作**：讀現有材料，建立來源清單；確認使用目的、主要受眾、公開範圍與是否已有同名檔案。只追問會改變結果的缺口。

**理由**：品牌定位若混入不該公開的資料，或一開始就把舊 profile 覆寫，後續很難追溯。

**通過判準**：知道材料來源、隱私邊界、輸出路徑與覆寫策略；每份會採用的材料都有 Source ID。

### Phase 1：顧問式訪談，挖行為而非優點

**動作**：依「事件 → 當時選擇 → 為何這樣做 → 代價 → 是否重複」追問。每輪 3–5 題，優先問矛盾、失敗與反覆出現的行為；把回答寫回來源筆記，不急著下定位。

可用問題：

- 哪三次不同情境中，你做了相似但不一定討喜的選擇？
- 哪件失敗改變了你後來的固定做法？
- 別人最常因為什麼具體事情來找你，而不是怎麼稱讚你？
- 哪個看似合理的方向，你做過後確定不想長期維持？

**理由**：「真誠、專業、有溫度」等抽象優點容易套在任何人身上；具體選擇、代價與重複事件才有辨識力。

**通過判準**：至少有多個不同事件可交叉比較，並收集到矛盾或反例；若只有單一故事，不升級為 pattern。

### Phase 2：建立 pattern 與證據表

**動作**：先逐筆編碼觀察，再合併成 pattern。每個 pattern 填 Evidence table，附反證與限定情境。建議 high confidence 至少由兩個不同事件或作品支持；只有一項證據時標 medium/low 並繼續問。

**理由**：把證據先於敘事，可減少 AI 為了完整而補齊人格故事。

**通過判準**：每個保留的 pattern 都有來源；事實、使用者原句與推論能清楚區分；沒有證據的主張已刪除或降級。

### Phase 3：把 pattern 篩成可驗證品牌資產

**動作**：逐項檢查是否容易被記住、是否與本人經驗組合綁定、是否願意長期投入；補上可驗證作品、連結、數字或公開紀錄。資產不一定是成就，也可以是罕見的經驗組合或反覆實踐的方法。

**理由**：有辨識度但無法證明，容易變成口號；可以證明但不願長期做，也不適合當品牌主軸。

**通過判準**：選出至少 3 個可驗證資產，每個都有證據與可持續性判斷；證據不足者放入 experiment，不包裝成既定優勢。

### Phase 4：收斂方向，寫入 profile

**動作**：用模板完成一句定位、受眾、內容支柱、立場、反例與不做清單。把 pattern、資產與方向用 ID 串起來。訪談不設定硬性 3–5 天：當連續兩輪沒有出現新的高信心 pattern，且關鍵矛盾已有解釋或明確保留時，視為證據趨於飽和；否則繼續補問。

**理由**：時間不是品質指標，證據飽和度才決定是否該收斂。

**通過判準**：每個內容方向可回指 pattern/asset；反例能說明「什麼看似適合、其實不適合」；不做清單具體到能否決題目。

### Phase 5：用真實決策驗證

**動作**：拿 3–5 個近期題目、合作邀請或內容草稿測試：保留、調整或拒絕，並寫出 profile 中的依據。請使用者檢查結果是否像自己的判斷，而不是只覺得文句好看。

**理由**：profile 的價值在能否改善選題與取捨，不在文件看起來完整。

**通過判準**：至少 3 個案例能得到可解釋的決策；遇到錯判時已修改規則、限定情境或信心，不掩蓋例外。

## 完成定義

只有同時符合下列條件，才可標 `status: validated`：

- `brand-profile.md` 已建立且使用者確認核心定位沒有美化事實。
- 每個核心 pattern 都在 Evidence table 有來源與反證/限定情境。
- 至少 3 個品牌資產可由作品、連結、具日期紀錄或其他外部材料驗證。
- 內容方向可回指 pattern 與 asset，不只是流行題目。
- 有具體反例與不做清單，能在實際題目中排除不適合的方向。
- 已以至少 3 個真實決策案例驗證，未解問題仍明確列出。

## 失敗與回復

- **答案很通用**：回到 Phase 1，要求事件、選擇與代價；刪除無法區分使用者的形容詞。
- **證據互相矛盾**：不要硬合併成一致人格；記錄限定情境，必要時拆成兩個 pattern。
- **使用者答到疲乏**：保存來源 ID、已驗證與未驗證清單，下次從缺口續跑，不重問已知事實。
- **AI 改寫了事實**：以來源原文還原 Evidence table，將推論移出事實欄，再重做受影響段落。
- **誤把 voice 寫進來**：移除節奏、口頭禪、標點等表達規則，交給獨立 voice profile。
- **舊檔被不當覆寫**：從備份或版本控制恢復；新版先存成候選檔，再由使用者決定是否取代。

## 隱私與侷限

- Profile 可能包含身分、失敗、客戶與未公開計畫；只收集定位需要的最少資料，不把 raw interview 自動公開或提交版本庫。
- 引用第三人或受保密約束內容前先去識別化；不要把密鑰、帳務、醫療或法律敏感資料放進 profile。
- AI 能協助找 pattern，不能證明人格真相。輸入偏差、只挑高光材料或迎合式回答都會影響結果。
- 「別人記得住、學不走」是實務篩選準則，不是可保證的市場結果；仍需靠真實內容與受眾反應驗證。

## 維護與迭代

- 使用語意版本：小幅證據補充升 patch；定位或支柱調整升 minor；核心受眾/方向改變升 major。
- 每次更新只改受新證據影響的段落，保留版本紀錄與舊檔，不因一次內容偏離就整份重寫。
- 新作品或受眾回饋先加入來源清單，再判斷是強化、限定或推翻既有 pattern。
- 當持續出現 profile 無法解釋的決策，回到 Phase 2–5 重新驗證；不要硬把新行為套回舊定位。
