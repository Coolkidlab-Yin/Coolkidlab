# Brand profile 鎖定(brand-profile-lockdown)

## 什麼時候用

- 發了一陣子內容,累積起來沒有一條主線,新讀者進來不知道你在幹嘛
- 寫東西沒方向、三天一個 pivot,問題不是「不會寫」是「不知道自己是誰、該往哪寫」
- 想把品牌定位鎖成一份檔案,以後寫文章 / 拍影片前讀一遍對齊,AI 卡住時丟給它當 context
- 自己想會鬼打牆 — 離自己太近,看不清

## 方法核心:AI 當顧問「探討」,不是「給答案」

直接叫 AI「給我一個品牌定位」只會拿到通用答案 — 「真誠、專業、有溫度」這種誰都能套等於沒用的東西。AI 不認識你,它只能從你問問題的那幾句話猜,猜出來的當然通用。

這套方法反過來,兩個關鍵動作:

1. **先餵背景**:把你的成長經歷、做過的事、失敗過的事、在意的東西,整段寫給 AI — 這是它認識你的唯一來源。
2. **叫它「當顧問」不是「當寫手」**:讀完背景後不急著給定位,先針對你這個人反問一串問題,一輪一輪挖。被問的時候,你才會講出一些自己平常沒意識到的 pattern。

幾輪問答下來,一起整理出三層:

| 層 | 挖什麼 | 判斷標準 |
|---|---|---|
| 1. 個性 pattern | 反覆出現的特質 — 不是挑優點,是「就是會這樣」的模式 | 連你的毛病都算 |
| 2. 品牌資產 | 這些特質裡哪些能變成品牌 | 別人記得住、學不走、跟你這個人綁在一起 |
| 3. 長期方向 | 哪些方向你碰得到又願意長期做 | 不是看起來厲害但你會撐不住的 |

最後鎖定成一份 brand profile 檔案(例如 `brand-profile.md`),內含核心 pattern、定位、「永遠不寫什麼」的清單。AI 顧問真正的價值不是給答案,是逼你把模糊的自我認知,一句一句講到清楚 — 定位是你自己生出來的,AI 只是助產士。

## 照步驟做

### 步驟 1:準備背景素材

先把要餵給 AI 的背景整理出來,涵蓋四類:

- 成長經歷
- 做過的事
- 失敗過的事
- 你在意的東西

不用寫得漂亮,重點是誠實、夠具體。有過去的貼文、筆記也一起給 — 在 Claude Code 裡跑的好處是它能讀你丟進去的所有檔案,跨多輪對話持續 context,幾天的訪談不會忘前面的細節。

### 步驟 2:貼顧問 prompt,啟動訪談

把下面整段貼給你的 AI agent,它就能照著當你的品牌顧問:

> 我要你當我的個人品牌顧問,陪我把「我是誰、哪些個性能變成品牌」想清楚,最後一起鎖出一份 brand profile 文件。你不是幫我寫文案的寫手,是逼我講清楚的顧問。
>
> 請避開這幾個雷,我踩過:
> 一、不要直接丟給我一句「你的品牌是真誠專業有溫度」這種通用定位,那種誰都能套等於沒用。我要的是從我的背景長出來、別人記得住也學不走的東西。
> 二、不要讀完背景就急著給答案。你要先當顧問多問少寫,一輪只問我三到五題,等我答完再追下一輪,把我自己沒意識到的個性、矛盾、反覆出現的行為模式挖出來。
> 三、我講的個人事實,像經歷、失敗、做過的事、數字,是唯一事實來源,你不要擅自改寫或美化。
> 四、brand profile 管「我寫什麼、立場是什麼」,跟管「怎麼寫、什麼語氣」的 voice profile 是兩件事,這次只做 brand profile,不要混在一起。
>
> 幾輪問答之後,我們再一起整理出三層:第一層是我反覆出現的特質,不是挑優點,是「就是會這樣」的模式,連我的毛病都算;第二層是這些特質裡哪些能變成品牌資產,標準是別人記得住、學不走、跟我這個人綁在一起;第三層是哪些方向是我碰得到又願意長期做的,不是看起來厲害但我會撐不住的。
>
> 開始前,請先問我兩件事再動工:一,我想先用哪一個 AI 工具來跑這套對話;二,我準備好要餵給你的背景大概涵蓋哪些,像成長經歷、做過的事、失敗過的事、我在意的東西。確認完再帶我一步步做,每進一輪都先跟我確認方向對不對,別自己一路衝到底。

### 步驟 3:一輪一輪答,別急著收斂

顧問式追問的輪次結構是:從個性 pattern 一路問到可用方向。一輪三到五題,答完再追下一輪。這個過程急不得 — 被問到平常沒意識到的矛盾時,那正是最有料的地方。整套跑下來抓 3-5 天的量級,不是一個下午。

### 步驟 4:整理三層,鎖成 profile 檔

問答收斂後,跟 AI 一起把三層(pattern → 資產 → 方向)整理成一份 `brand-profile.md`。判斷一個特質能不能變品牌資產,用三個標準過:

1. 別人記得住
2. 學不走(跟你這個人綁在一起)
3. 你願意長期做

### 步驟 5:開始用

- 寫文章 / 拍影片 / 接受訪談前先讀一遍,確認沒偏離
- 寫東西 AI 卡住時,把這份丟給它當 context,方向立刻對齊
- 幾天的投入,換的是接下來很長一段時間內容方向不偏

## 我踩過的坑

1. **直接叫 AI「給我一個品牌定位」** — 拿到「真誠、專業、有溫度」這種放諸四海皆準的東西,等於沒用。要它給出對的東西,得先讓它真的認識你,而且最好的方式不是讓它寫,是讓它問。
2. **AI 讀完背景就急著給答案** — prompt 裡要明確要求「多問少寫」,一輪只問三到五題,不然它會跳過探討直接產一份看起來完整、其實通用的定位。
3. **AI 擅自美化你的事實** — 個人經歷、失敗、數字是唯一事實來源,要在 prompt 裡講死「不要改寫或美化」,不然 profile 會失真,以後照著寫等於在演別人。
4. **brand profile 跟 voice profile 混在一起** — brand profile 管「寫什麼、立場是什麼」,voice profile 管「怎麼寫、什麼語氣」,兩份分開維護,寫東西時一起用。一次只做一份。
5. **覺得自己「沒什麼特別經歷」就不跑** — 「特別」是相對的。重點不是單一經歷夠不夠精彩,是「組合」夠不夠少見。舉個虛構例子:「會寫程式」不稀奇、「在傳統產業上班」也不稀奇,但「在傳統產業裡用程式自動化自己的工作、還公開記錄過程」這個組合就少見。這種組合要靠被反問才挖得出來,自己想通常想不到。

## 注意

- **教方法不教內容**:每個人跑出來的 brand profile 都不一樣,別人的內容公開了對你也沒用。定位是私人的,方法可以共用 — 這個 skill 給的是方法和 prompt,profile 內容你自己跑。
- **profile 是活文件,不是刻在石頭上**:用法本身就內建校準 — 每次產出內容前讀一遍「確認沒偏離」。發現持續偏離時,別硬凹回舊 profile,回去跟 AI 顧問補跑幾輪問答,把變化更新進去;方向真的 pivot 了就重新整理三層。更新走「小改累積」,不要動不動整份重寫,不然鎖定就失去意義。
- **工具選擇**:需要跨好幾天、多輪對話、能讀你歷史檔案的環境,file-based 記憶的工具(如 Claude Code)比單次網頁對話適合 — 網頁對話到後面會忘前面的細節。
