# 12 — 目的地別重點

**這一份只記「這個地方特別容易漏掉什麼」，不記規則。**
入境規定一律走 `01-passport-visa.md` 的鐵律：導向官方，不要背。

---

## 日本

| 容易漏 | 說明 |
|---|---|
| **線上入境表** | 有 Visit Japan Web 這個東西，要不要用查官網 |
| **兩個機場** | 東京成田（遠）／羽田（近）；大阪關西／伊丹 |
| **周遊券要先想清楚** | 只待一個城市通常不划算 |
| **現金** | 比想像中更多地方只收現金，尤其小店和神社 |
| **藥品** | 有些台灣常見成藥在日本是管制品，反之亦然 |

**連假資料有涵蓋日本**，所以 🎌 會標。黃金週、盂蘭盆節、年末年始是三大高峰。

---

## 韓國

| 容易漏 | 說明 |
|---|---|
| **K-ETA** | 有這個東西，是否需要辦一定要查官網 |
| **檢疫申報** | Q-CODE，看當時政策 |
| **兩個機場** | 仁川（遠）／金浦（近） |
| **交通卡** | 落地買就好 |

**連假資料沒有韓國。** 表上沒有 🎌 **不代表沒連假**——
韓國的春節（설날）和中秋（추석）影響很大，要提醒他自己查。

---

## 泰國

| 容易漏 | 說明 |
|---|---|
| **線上入境卡** | 有數位入境卡，查官網 |
| **兩個機場** | 素萬那普／廊曼（廉航多），進市區差很多 |
| **雨季** | 影響行程，也影響班機延誤機率 |
| **現金** | 市場、攤販、計程車多半收現金 |

**連假資料沒有泰國。** 潑水節（宋干節）期間全國幾乎停擺，要自己查日期。

---

## 東南亞（越南、菲律賓、印尼、馬來西亞）

| 容易漏 | 說明 |
|---|---|
| **簽證形式差很多** | 有電子簽、落地簽、免簽，**一國一個樣，一定要查** |
| **護照效期** | 這區對效期要求普遍嚴格 |
| **回程機票證明** | 有些國家入境要出示，先準備好電子檔 |
| **雨季／颱風季** | 影響行程與班機 |

---

## 美國、加拿大

| 容易漏 | 說明 |
|---|---|
| **電子旅行許可** | ESTA／eTA，要事前辦，有效期與可停留天數是兩回事 |
| **入境審查較嚴** | 準備好行程、住宿、回程機票資訊 |
| **小費文化** | 餐廳、計程車要另外給，預算要抓進去 |
| **醫療費極高** | **海外醫療險在這裡最值得** |
| **境內航班要另外算轉機時間** | 國內線也要重新安檢 |

---

## 歐洲（申根區）

| 容易漏 | 說明 |
|---|---|
| **ETIAS** | 有這個東西，是否已上路查官網 |
| **護照發照年限** | 申根對「發照日起算幾年內」也有要求，不只看到期日 |
| **停留天數是整區合計** | 不是一國算一次 |
| **跨國移動** | 火車要訂位、廉航行李規定嚴 |
| **扒手** | 大城市車站與景點，貴重物品分開放 |

## 目的地不在這份表裡

**直說沒有資料，然後：**

1. 入境規定 → 搜尋「<國家> 台灣護照 入境」找官方來源，或問駐台辦事處
2. 當地假期 → 搜尋「<國家> <年份> public holidays」
3. 治安、旅遊警示 → 外交部旅外安全資訊

**不要憑印象補。** 冷門目的地正是最容易講錯的地方，而且使用者最沒有能力發現你錯了。

---

## 通用提醒（所有目的地都適用）

- **護照效期 6 個月**是常見門檻，但**以目的地官方為準**
- **回程機票證明**：有些國家入境要看
- **住宿地址**：入境表和海關可能會問，**存在手機裡**
- **行動電源只能手提**
- **駐外館處電話**：出發前存好
