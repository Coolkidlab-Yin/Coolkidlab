## 五個時間層

按 Tier 順序推進。每個模組的節奏見 SKILL.md：
說明 → 去哪辦 → 截止日 → 確認 → 過渡。

### ▌Tier 0 — 出發前先確認（沒過這關，訂什麼都白訂）

**M1 — 護照效期**
一句話：多數國家要求入境時護照剩餘效期 **6 個月以上**，不是「還沒過期就好」。
要問：「你的護照到期日是什麼時候？」
去哪辦：外交部領事事務局（本人親辦或委任旅行社）
截止：換發要工作天，**這是整趟最早該確認的一件事**
Reference：`01-passport-visa.md`

**M2 — 簽證／入境許可**
一句話：台灣護照很多地方免簽，但「免簽」不等於「什麼都不用辦」——
很多國家改成線上事前許可（電子簽、ETA 類）。
**⚠ 不要背規則，導向官方。** 見 SKILL.md 的入境規定鐵律。
截止：有些要 3–5 個工作天，有些當天核發。**先查再訂機票。**
Reference：`01-passport-visa.md`

**M3 — 撞不撞連假**
一句話：出發地或目的地的連假會讓住宿翻倍、票券賣光、交通擠爆。
工具：`data/holidays.json`（**只收台灣與日本**，其他地區要自己查）
Reference：`02-timing.md`

---

### ▌Tier 1 — 現在就要訂（會賣完、會漲）

**M4 — 機票**
一句話：這個 skill **不比價**。要比哪天便宜，用 Google Flights 結果頁的「日期網格」按鈕。
這裡只講**訂之前要確認什麼**：行李額度、轉機時間夠不夠、廉航的隱藏成本、
同一段掛兩個航空公司名是聯營。
Reference：`03-flights.md`

**M5 — 住宿**
一句話：位置比價格重要——離車站 10 分鐘和 30 分鐘，五天下來差很多時間。
要問：「你想住熱鬧的地方還是安靜的？有沒有要帶大行李？」
Reference：`04-accommodation.md`

**M6 — 需要預約的票券**
一句話：有些東西**不是貴，是根本買不到**——樂園快速通關、熱門展覽、
需要事前抽選的餐廳、季節限定活動。
截止：熱門的提前 1–3 個月，**這是最容易後悔的一項**
Reference：`05-tickets.md`

---

### ▌Tier 2 — 出發前 2 週

**M7 — 交通票券／周遊券**
一句話：周遊券划不划算取決於行程，**不是買了一定賺**。要先知道他大概去哪幾個城市。
有些券**只有在國外買得到、或只有在台灣買得到**，別買錯。
Reference：`06-transport.md`

**M8 — 租車＋國際駕照**
一句話：**國際駕照要在台灣先辦**，出國之後辦不了。監理站當天可領。
有些國家還要求帶正本台灣駕照。
Reference：`06-transport.md`

**M9 — 旅遊保險**
一句話：信用卡附的旅平險通常只保「搭乘期間」，不保旅程中生病。
要問：「你刷哪張卡買機票？」
**不給保單建議，只講有哪幾類、差在哪。**
Reference：`07-insurance.md`

---

### ▌Tier 3 — 出發前 3 天

**M10 — eSIM／網卡**
一句話：eSIM 現在多數手機支援，出發前買、落地開，不用等櫃檯。
要確認手機支不支援、有沒有鎖網。
Reference：`08-connectivity.md`

**M11 — 線上入境表**
一句話：很多國家改成線上填，有些要**入境前 72 小時內**才能填。
**⚠ 規定會變，導向官方。**
Reference：`01-passport-visa.md`

**M12 — 換匯與海外刷卡**
一句話：不用換一大包現金，但要有一點。刷卡要先確認海外手續費、
以及有沒有開通海外交易。
**不給投資或匯率預測建議。**
Reference：`09-money.md`

---

### ▌Tier 4 — 落地後再說

**M13 — 交通卡**
一句話：多數地方落地買就好，不用在台灣先買。有些手機可以直接加卡。
Reference：`06-transport.md`

**M14 — 行李寄放**
一句話：早班機到、晚班機走的那兩天，行李放哪很影響體感。
Reference：`10-on-the-ground.md`

**M15 — 退稅**
一句話：門檻、流程、要不要在機場排隊，每個國家不一樣。
**買之前就要問店家能不能退，事後補不了。**
Reference：`09-money.md`

### ▌Tier 5 — 情境模組（按需插入，不佔主流程）

**M16 — 特殊同行者**
帶小孩（嬰兒票、推車、時差）、帶長輩（走路距離、醫療）、

## 腳本：產出帶實際日期的清單

**在 skill 目錄下執行**（`skills/trip-guide/`）：

```bash
python scripts/trip_checklist.py --to 韓國 --depart 2026-10-13 --days 5 --people 1
```

| 參數 | 意思 | 預設 |
|---|---|---|
| `--to 韓國` | 目的地（國家或城市，純文字） | 必填 |
| `--depart 2026-10-13` | 出發日 | 必填 |
| `--days 5` | 幾天 | 必填 |
| `--people 1` | 幾個人 | 1 |
| `--from 台北` | 出發地 | 台北 |
| **`--tier 1`** | **出到第幾層**（`0`–`4` 或 `all`） | **`0`** |
| **`--no-links`** | **不要帶推薦連結** | — |
| `--first-time` | 第一次出國，加進 M17 | — |
| `--driving` | 要租車，把國際駕照拉到前面 | — |
| `--kids` / `--seniors` | 帶小孩／長輩，加 M16 | — |
| `--out 檔名.md` | 寫檔 | 直接印出 |

### `--tier` 預設是 0，這是閘門不是限制

**一開始只會給你 Tier 0，而且零推薦連結。** Tier 0 確認完才加 `--tier 1` 往下開。

**使用者說「全部列給我」→ `--tier all --no-links`。**
給他看關卡全貌是一回事，在他卡在 Tier 0 的時候推東西是另一回事。

### 連假只比對相關地區

腳本會從 `--from` 和 `--to` 判斷要比對哪幾區。

- **對得到**（台灣、日本及其主要城市）→ 標成「日本年末年始」「台灣元旦」，分得出哪一邊
- **對不到**（韓國、泰國、美國⋯⋯）→ 表頭直接印警告說**沒有查過目的地假期**

**以前所有地區的連假會全部撈進來**——一趟美西行程被標上日本的年末年始，
使用者會以為系統查過目的地了。現在不會了，但**對不到的時候要把那句警告轉述給使用者**。

**腳本不連網、不查價、不查簽證規則。** 它只做三件事：
把 Tier 展開成實際日期、標出相關地區的連假、把設定好的推薦連結帶進去。

**產完不要整張倒給使用者**，照 Tier 順序一次講一段。
