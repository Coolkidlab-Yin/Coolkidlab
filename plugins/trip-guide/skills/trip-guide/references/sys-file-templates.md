# sys — `trip-plan.md` 模板

**什麼時候建檔：** 只有完整規劃模式。快速盤點和單點問答**不要建檔**。

**寫入原則：先 Read 比對，再 Write。** 使用者可能自己打了勾、自己加了註記，
直接覆寫會把他的東西弄丟。

---

## 模板


## 維護規則

**每次 Write 之前：**

1. **Read 現有檔案**
2. **保留所有 `[x]`**——那是他自己打的
3. **保留他手寫的註記**（例如某一項後面自己加的備註）
4. 只更新：最後更新日期、新完成的項目、新的下一步

**不要做的：**

- 不要因為格式不合就整份重寫
- 不要把 `[x]` 改回 `[ ]`
- 不要刪掉他自己加的行

---

## 檔案放哪

**放使用者當前的工作資料夾**，檔名 `trip-plan.md`。

**同時規劃多趟**：檔名加目的地，例如 `trip-plan-韓國.md`。
開場先看有沒有多個檔案，有的話問他這次要接哪一趟。
